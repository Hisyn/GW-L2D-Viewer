# Girl Wars L2D Viewer

Website to check the animations of the characters from the gacha game Girl Wars.<br/>
If you want to request a feature or report a bug you can open an issue.

## Based On

This project is based on [Jelosus2/BD2-L2D-Viewer](https://github.com/Jelosus2/BD2-L2D-Viewer).<br/>
Please check his repo and support him if you can! <br/>

The code has been configured to support Spine2D 4.0 models, and includes new functionality for displaying Live2DCubism 4.0 models, along with various UI improvements and retouches.
